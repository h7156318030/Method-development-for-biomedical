# Code of Conduct

MethodFlow adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text applies; the summary below is for quick reference.

## Our standard

Be respectful and constructive. Assume good intent, critique the work rather than the person, and keep discussions
about regulated practice factual. Harassment, personal attacks, discrimination, publishing other people's private
information, and sharing credentials or confidential documents are not acceptable.

## Reporting

Report unacceptable behaviour to the maintainers through GitHub's private reporting described in
[SECURITY.md](SECURITY.md) (choose the option for conduct concerns in the report text). Reports are read by the maintainers
and kept confidential as far as possible. The maintainers may take any action consistent with the Covenant,
from a warning to a permanent ban from the project.

## Scope

This code applies in project spaces (issues, pull requests, discussions, and any other channel the project uses)
and when representing the project in public.
